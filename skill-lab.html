MWI Skill Lab

Ability-kit bench for one raid member · For IC guild Arsenal internal use only. ← Group Battle Standard simulator ↗ Trial pages

Load your guild's combat-trial export, pick one member, and give them several ability kits. Every kit is run in the whole party's fight, exactly as the Group Battle page runs it, on the same wasm combat kernel. Only that member's bar changes. Each kit is run 10 times by default, on the same seeds as every other kit, and the results table compares each kit's average damage with the first kit. An ability the player already has equipped keeps their own level. The export has no level for any other ability, so those start at 60 for the 0-cooldown spells (Entangle, Fireball, Water Strike), 20 for auras and other special abilities, and 40 for everything else. You can change any level.

Party

The guild combat-trial export: one JSON file holding every member. It is imported the same way as on the Group Battle page. Each member's saved trial loadout wins, and a member without one falls back to what they had equipped. Food and drinks are ignored, and the enemy switches to the trial's monster. The party is remembered in this browser.
